# 🧠 DSA & Logic Practice – Coding Questions Collection

This repository contains **commonly asked coding interview questions** focused on  
**numbers, arrays, strings, recursion, math logic, and patterns**.

The goal is to strengthen **problem-solving skills**, **logic building**, and **coding confidence** for backend / full-stack interviews.
